# Udhayasankar R — Digital Marketing Portfolio

A polished, responsive one-page portfolio for an independent digital marketer focused on Meta Ads, lead generation, Instagram/Reels and creative content for real estate and local businesses.

## Run it

Open `index.html` in a browser, or open this folder in Visual Studio Code and use any local static server / Live Preview extension. There is no build step, package installation or framework dependency.

## Publish with GitHub Pages

1. Create a GitHub repository for this portfolio and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages** and choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save. GitHub Pages will provide the public site URL in the same settings page.

The included media library is about 330 MB. All supplied individual media files are below GitHub's 100 MB per-file limit; videos are loaded from the page only when a visitor presses play.

## Customize before publishing

1. Your name, role and contact links are filled in. WhatsApp links use international digits only in the `wa.me` URL.
2. Replace the testimonial placeholder only after you have an approved client quote and attribution.
3. Replace or add project photos, ads or Reels as you choose. Keep permission to publish in mind.
4. Update the page title and meta description near the top of `index.html` if you change your positioning.

## Files

- `index.html` — page content and section structure
- `styles.css` — responsive layout, artwork and motion
- `theme.css` — cinematic charcoal-and-brass visual theme
- `script.js` — mobile menu, scroll reveal, gallery filters, poster preview and click-to-play videos
- `assets/marketing-campaign-hero.png` — illustrative digital campaign hero visual
- `assets/udhaya-profile.jpg` — supplied profile portrait used in the profile section
- `assets/logos/signal-story-02-dark.svg` — selected Storyline logo for the dark portfolio header and footer
- `signal-story-logo-options.html` — original Signal & Story logo concepts and SVG downloads
- `assets/posters/` and `assets/videos/` — 13 posters and 11 MP4s from the supplied archive

The Meta lead card reports 339 exported lead records from 15 September through 4 October 2026, deduplicated by lead ID across the supplied lead files. Raw CSVs, names, phone numbers and email addresses are not included in the website. It does not claim lead qualification or conversion rates.

The gallery includes all supplied posters and promotional videos, with category filters, pagination and an image preview. Videos load only when the visitor presses play. The bundled media is about 342 MB; remove any pieces you do not want to publish before uploading the folder to a host.
